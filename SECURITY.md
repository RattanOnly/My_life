# Security Policy

## Supported scope

This is a personal Hexo blog repository. Security reports should focus on repository code, configuration, scripts, dependencies, or deployment workflow.

Personal posts, images, audio, video, and other private content are not security targets unless they accidentally expose credentials or sensitive personal information.

## Reporting a vulnerability

If you find a security issue, please open a GitHub issue with a clear description, or contact the repository owner through GitHub.

Please include:

- affected file or workflow
- reproduction steps
- potential impact
- suggested fix, if available

## Sensitive information

Do not publish secrets, tokens, private keys, cookies, or personal information in issues or pull requests. If you notice exposed credentials, report it with minimum necessary detail so it can be rotated and removed safely.
